# 🖤 Blacky Assistant

Blacky Assistant is a Python desktop assistant project built with **Tkinter**.

The project is currently under active development and is being used to learn and improve skills in **Python, GUI development, system information, and software development**.

## 🚀 Current Version

**v0.4.0**

## ✨ Features

### 🧮 Calculator

* Addition
* Subtraction
* Multiplication
* Division
* Simple graphical interface

### 🖥️ System Information

Blacky Assistant can display information about the computer it is running on:

* Operating system
* OS version
* Kernel
* Architecture
* Hostname
* Processor
* CPU usage
* GPU
* RAM
* RAM usage
* Storage
* Disk usage
* Free disk space
* Python version

### 🖤 Blacky Assistant Information

Blacky Assistant also displays information about itself:

* Current version
* Running status
* GUI framework
* Python version

## 🛠️ Technologies

* Python 3
* Tkinter
* psutil
* PowerShell

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/blackySascha/BlackyAssisstant
cd BlackyAssistant
```

Install the required package:

```bash
python -m pip install psutil
```

Run Blacky Assistant:

```bash
python main.py
```

## 💻 Requirements

* Windows
